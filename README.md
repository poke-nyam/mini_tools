# mini_tools
htmlとcss,jsで動く、ちょっと便利なツール。  
どのツールもサーバーに送信されず、Webで完結するため、セキュリティも考慮してある。(はず)
## totp_generator
GitHubとかGoogleとかMicrosoftとかのアカウントのTOTP認証のコードを生成するよ。  
最初にOSとかに保存するためのパスワードが必要だから、忘れたら一巻の終わり。責任はとんないからね。(嫌なら保存してくださいな。)
